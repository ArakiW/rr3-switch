# THE ROOT CAUSE THIS POINTS AT

The recovery is supposed to back the car off a barrier and point it down the
track again.  Its code says so:

    // WHILE REVERSING, HOLD A DECISIVE ANGLE THE OTHER WAY.  The car has
    // to come off the barrier pointing back down the track ...
    // BUT THE PURSUIT WINS.  MEASURED 2026-11-02 (q114): the pursuit was ON
    // in 0 of 228 samples, so every steering value in that round was this
    // recovery's full lock -- the pursuit never got a say.

So the pursuit overrides the recovery's steering.  That was right when the
pursuit never engaged (q114).  It is wrong now: the pursuit IS engaged (pur=1),
it holds the error at 90 degrees, it commands FULL LOCK, and the recovery is
BRAKING AT THE SAME TIME.  A brake plus a full lock is a SPIN.  The recovery's
reversing angle never gets a say, the car never comes off the barrier, the
stall counter runs up (stalls=5), and the round ends with the car creeping in
circles.
